# Search & Filter Feature Demo

A small practice project that adds search and filter functionality to a static HTML page. Built to validate the structure and logic of a client-side filter before applying it to a real site, using fictional data only.

## Features

- Instant keyword search across multiple fields
- Dropdown filters with combined AND logic (unit, rank, status)
- Expandable row for detailed information
- Empty-state UI and live result count

## Tech

- Vanilla JavaScript (`querySelectorAll`, `Array.filter`)
- No frameworks or libraries — plain HTML, CSS, and JS

## What I learned

- DOM manipulation and event-driven real-time filtering
- Combining multiple filter conditions with AND logic
- Structuring reusable filter functions for future extension
